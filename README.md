# ptf1 — Gopal Singar · Portfolio

Personal portfolio site for Gopal Singar — B.Tech CSE at Academy of Technology, Kolkata.

Built with HTML, Tailwind CSS, and a little vanilla JS. Single-page, dark/light themed, fully responsive.

## Files

- `ptf1.html` — main page
- `img1.png` — hero image
- `.gitignore` — excludes OS/editor clutter

## Run locally

Just open `ptf1.html` in any browser. No build step.
